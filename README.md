# えんメイト（個人開発版）

車で遠くの試合やライブへ行くときの、往復のドライブプランを作る Web アプリです。

**状態: 開発中（段階1まで実装。本人の操作確認待ち）**。段階ごとにこの README を更新します。

- 設計書: [docs/design.md](docs/design.md)
- 使う技術: Nuxt（Vue 3）、TypeScript、Leaflet、Vitest

## 今できること（段階1: 日帰りプラン）

- 出発地と会場を名前で検索して選び、試合日・会場に着きたい時刻・試合の終了時刻を入れる
- 「計算する」を押すと、家を出る時刻と、家に帰り着く時刻が出る（運転時間・距離・高速料金つき）
- プランを保存し、一覧と閲覧ページで見返す。閲覧ページでは地図にルートが出る
- トップ画面では、これからの遠征をチケットのように並べ、試合日まで「あと○日」かを出す。終わった遠征は「遠征完了済み」にたたんでまとめ、行った回数・走った距離・高速料金の合計を出す
- 保存したプランを編集して上書き保存する、削除する
- NAVITIME の今月の使用回数の目安を表示する

時刻は渋滞を考慮していません。高速料金は ETC・普通車の料金で、休日や深夜の割引は反映されないことがあります。

宿泊、立ち寄り先、休憩地の提案、当日ページは、これから作ります（設計書 §11）。

## 動かし方

```bash
npm install
cp .env.example .env   # RAPIDAPI_KEY を入れる
npm run dev            # http://localhost:3000 で開く
```

RapidAPI で、次の2つの API を購読しておく必要があります（それぞれ無料枠は月500回）。

- NAVITIME Route(car)（ルート検索）
- NAVITIME Spot（場所の検索）

無料枠を使いすぎないよう、検索するのはボタンを押した時だけにしています。同じ条件の結果は、ブラウザに保存して使い回します。

## テスト

```bash
npm test            # 自動テスト
npm run typecheck   # 型チェック
```

テストの名前に付けた番号（E1、F2 など）は、設計書 §10.3 の「期待する結果」「失敗しそうな点」の表の番号です。確認したこと・未確認のことも、同じ節にまとめています。
